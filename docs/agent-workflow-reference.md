## 🔄 詳細流程分解

### 第一層：輸入處理 (Input Processing)

```
用戶輸入
    ↓
┌─────────────────────────────────┐
│ 1. 自然語言理解 (NLU)            │
│                                │
│ 輸入："幫我生成Q3銷售報告      │
│        並寄給行銷經理"          │
│                                │
│ ✓ 意圖識別: [生成報告][發郵件] │
│ ✓ 實體提取: [Q3][銷售][行銷]   │
│ ✓ 參數解析: [報告類型][收件人] │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│ 2. 需求分解 (Task Decomposition)│
│                                │
│ 主任務: 生成並寄送銷售報告       │
│                                │
│ 子任務1: 蒐集 Q3 銷售數據      │
│ 子任務2: 分析銷售數據          │
│ 子任務3: 生成報告文件          │
│ 子任務4: 找到行銷經理郵箱      │
│ 子任務5: 發送郵件              │
└─────────────────────────────────┘
```

### 第二層：規劃層 (Planning Layer)

```
LLM 分析並規劃
    ↓
┌──────────────────────────────────────────┐

│  • sales-data-format.md                │

│  • reporting-standards.md              │
│                                         │
│ 需要工具:                               │
│  • Google Drive MCP (讀取檔案)          │
│  • Gmail MCP (發送郵件)                │
│  • 數據分析工具 (Pandas)                │

    ↓
┌──────────────────────────────────────────┐
│ 步驟2: 制定執行順序                      │
│                                         │
│ ┌─ 檢查前提條件                        │
│ │  ├─ 是否有 Q3 銷售數據？              │

│ │  ├─ 套用公司報告範本                │
│ │  ├─ 插入數據與圖表                  │
│ │  └─ 格式檢查                        │
│ │                                      │
│ └─ 第四階段：發送與記錄                │
│    ├─ 蒐集收件人資訊                  │
│    ├─ 撰寫郵件                        │
│    ├─ 發送附件                        │
│    └─ 記錄發送時間與回執              │
└──────────────────────────────────────────┘
```
